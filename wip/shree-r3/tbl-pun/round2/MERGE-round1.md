  - **U+093D ऽ (Shree's code 41, which the 7 composer writes as 40):**
    - Ctrl+Space `w` (an `escape` entry plus a sequence `Øw`) on pun-crtronic, pun-doe, pun-godrej, pun-itr, pun-raming and pun-roma.
    - Ctrl+Space `6` on pun-typewrit.
    - Shift+V (vk 86) on punjabi-inscript and pun-newroma.
    - Shift+W (vk 87) on pun-newroma.
    - Shift+B (vk 66) on pun-itr.
    - Shift+, (vk 188) on pun-varitype.
  - **pun-raming Shift+. (vk 190):** `"ੳਉ"` becomes `"ਉਂ"`. The key holds codes 42 69 62 and the composer writes 44 74, which is drawn ਉਂ.
  - **Keys Shree leaves empty become `""` (types nothing).** Before this, the application typed the raw ASCII, which a Shree font draws as a letter.
    - pun-doe vk 220 and vk 192 (base and shift).
    - punjabi-inscript vk 220 (base and shift).
    - pun-newroma vk 192 (base and shift).
    - pun-phonetic vk 220 (base and shift), and vk 192 base.
    - pun-raming vk 220 base.
    - pun-roma vk 221 shift.
  - **punjabi-inscript vk 192 base:** `" "`. Shree's INSCRIPT.PUN types a space on the backtick key (code 20).
  - If another copy also edited these layouts, re-run the script on the merged files. It throws if a slot it fills is already taken.
