BANGLA / ASSAMESE: HOW SHREE'S 7 COMPOSER (S8Ban764.dll) WRITES UNICODE TEXT IN SHREE-LIPI 7 BYTES
================================================================================================
Ground truth: ban7-groundtruth.json, built from what S8BanU64.dll (TutorGetMappedCodeW, Unicode) and
S8Ban764.dll (TutorGetMappedCode, raw bytes) answer for the same key:
  - every layer-0 key (and Ctrl+Space key holding a code >= 80) of the 42 shipped keyboards
    (27 .BAN + 15 .ASS, each loaded from its original path; all 42 captures stable): 3159 rows
  - 34044 probe sequences in Shree's typing order (pre-base sign struck first, reph struck after the
    base and its signs), 47 per probe keyboard file, 725 files (copies of ITR.BAN with the 48 conjunct
    slots rewritten); every generated sequence has a result row, no unstable file
  -> 37123 pairs, 29129 Unicode strings, 26300 with an accepted answer (truth), 4174 quirk rows.
Bytes are hex, one per glyph code. "C" = any consonant. Each rule is followed by examples straight
from the truth table (Unicode=bytes). The computed tables behind every rule are in the APPENDIX.

READ FIRST - which fonts these bytes are right for
---------------------------------------------------
The 7 composer's bytes match NO single installed font at ten codes. Kept as the composer wrote them.
- It uses the SHREE-BAN 4/5/6 meaning at the codes where the 7 and 4/5/6 families differ:
  ঃ = 40 (BAN7 draws a half-ন hook there; ঃ is at 96 in BAN7)   কঃ=41 A1 40
  half-ন hook = 96 (BAN7: ঃ)                                     ন্দ=96 83  ন্ট=96 69 A1
  subscript ্ন = 97 (BAN7: a spacing ৺-like sign)                ক্ন=41 97 A1
  ৺ = A5 (BAN7: subscript ্ন)                                     ৺=A5
  ধ্ম = 8C, ব্ঝ = A8 (BAN7: copies of ব and দ; no ধ্ম/ব্ঝ glyph)   ধ্ম=8C  ব্ঝ=A8 A1
  FF = zero-width filler between glyphs that do not join (BAN7: the spacing ligature ড়্গ)
                                                                দ্গ=83 FF 4B  ব্ব=A4 FF A4  —=2D FF 2D FF 2D
  25 for % (BAN7: a zero-width below mark; ASS7: no glyph)       %=25
  Rendered (tsk-ban/pics/t1.png, fam-codes.png): in SHREE-BAN7 কঃ draws ক + hook, ন্দ draws ঃদ,
  — draws -ড়্গ-ড়্গ-. In SHREE-BAN-xxxx / SHREE-ASS-xxxx (4/5/6) and Shree-Ass7-001/002 they draw right.
- Of the 22 family-differing codes (family-diff-456-vs-7.json "bangla") the composer EMITS

  NEVER emits 08 09 0A 0B-0F 1A-1F (the 4/5/6-only control-code glyphs ব দ ড়্গ / = ; + * — × ÷ [ ] ॥):
  for / = ; + * [ ] × ÷ ॥ … “ ” ৳ ৲ ৹ it gives no answer at all.
  (family-diff labels 4/5/6 0x8C/0xA8 as ঋ/ঝ; the rendered glyphs are the ligatures ধ্ম / ব্ঝ.)
- ব (code 71) and ৰ (code 26) standalone and before signs are written AF, ৱ (code 7C) A4:
  ব=AF বা=AF E0 বি=5B AF ৰ=AF ৱ=A4. In every installed SHREE-BAN font (7 and 4/5/6) AF draws ব্ল and A4
  draws ব; in SHREE-ASS fonts AF draws ৱ and A4 ব. Inside conjuncts the composer itself uses A4 for ব
  (ব্ব=A4 FF A4, ব্ল=A4 C3, ধ্ব=8B FF A4). So for ব the composer's AF is wrong in every font.
- Conclusion: before building a SHREE-BAN7 table from this file, check what SLNXT really types into a
  SHREE-BAN7 document (live TypeProbe test): either SLNXT remaps the composer output for 7 fonts (it
  carries VFC code/layout tables in SL8_VFC* shared memory and VFC{0}Layouts resources), or Shree's 7
  output is wrong for these codes. The Tutor answer cannot tell which.

--------
- No composer of its own (no S8Ass*.dll): the 15 .ASS keyboards are typed by S8BanU64/S8Ban764 with
  the same code table (ৰ = code 26, ৱ = code 7C). 188 codes are typed on both .ASS and .BAN keyboards;
  184 get identical 7 bytes, the other 4 differ only by the keyboard's phonetic/inscript typing mode.

- SHREE-ASS7-xxxx (S<dddd>896.TTF) shares the SHREE-BAN7 encoding (unlike SHREE-SAN7 vs DEV7): glyph
  compare SHREE-BAN7-0550 vs SHREE-ASS7-0550 = 212 of 218 codes identical; AF = ৱ (BAN7: ব্ল), B9 = ৰ
  (BAN7: র), and 25, 3A, 8D (ব্ড), 9E (ৱ) exist in BAN7 only. Shree-Ass7-001 (WASS7001) differs from

5. Reph (code 40, struck after the letter and its signs) - glyph A2
------------------------------------------------------------------
- On a letter with the spacer A1 the reph goes BEFORE the A1: র্ক=41 A2 A1 র্ত=74 A2 A1, also with the
  signs below and ঁ: র্কু=41 E5 A2 A1 র্কঁ=41 F2 A2 A1; with a pre-base sign: র্কি=5B 41 A2 A1
  র্কে=EC 41 A2 A1.
- After া ী ো ৌ it comes after the sign: র্কা=41 A1 E0 A2 র্কী=41 A1 E3 A2 র্কো=EC 41 A1 E0 A2

- Letters without a spacer: after the letter and every sign: র্খ=4A A2 র্খা=4A E0 A2 র্খং=4A 7D A2

- Accepted orders: ং/ঁ/ঃ struck before or after the reph (both kept where the composer keeps both signs).
- Quirks: ং or ঃ struck before the reph on a spacer letter is lost (র্কং typed ক ং reph = 41 A1 A2 A1);
